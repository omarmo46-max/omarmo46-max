## 🚀 Featured project

### [Magk.ai](https://github.com/omarmo46-max/magk-ai-android)
A private, on-device AI agent for Android. Bring your own model (Claude, GPT, Gemini…), with a real Linux sandbox, browser automation, skills, persistent memory and MCP support. Free and open source (GPL v3).
